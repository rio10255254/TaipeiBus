台北公車動態支援隱私政策

隱私政策

生效日期：2026 年 10 月 3 日
適用：台北公車動態 iPhone App · 開發者 Rio

本 App 不需帳號，沒有廣告、跨 App 追蹤或內建使用者行為分析服務。收藏與搜尋紀錄主要保存在你的手機。提供地圖、地點搜尋、公車資料與內容更新時，仍需要連接下列網路服務。

定位與手機方向

定位權限為選用，只在使用 App 期間取得位置，以尋找附近站牌、規劃行程與顯示地圖。手機方向用於地圖視角與方向光暈。最近位置可暫存在本機以加快下次定位；切到背景後停止定位更新。拒絕定位仍可手動搜尋與選擇出發地。

本 App 不將你的定位座標、手機方向或搜尋文字加入臺北市公車資料查詢，也沒有自建伺服器接收這些資料。

地圖與搜尋服務

  • Apple 地圖：地點搜尋文字、搜尋區域，以及步行路線的起終點由 Apple 的系統服務處理。開啟 Apple 地圖導航時，會交由該 App 處理所選路線。詳見 Apple 地圖與隱私。
  • OpenFreeMap：底圖、字型及圖示透過網路載入。圖磚請求會透露你正在查看的地圖範圍及一般連線資訊，並不等同於上傳手機定位座標。供應者保留不含 IP 的基本匿名服務紀錄；安全事件期間可能暫存 IP，依其政策最多 30 天。詳見 OpenFreeMap 隱私政策。
  • AWS Terrain Tiles：地形陰影的高度圖磚由 Amazon Web Services 開放資料服務（s3.amazonaws.com）提供。請求會透露你正在查看的地圖範圍及一般連線資訊，不含定位座標、搜尋文字或收藏；Amazon 可能依其政策處理 IP 等連線紀錄。詳見 AWS 隱私聲明。
  • 臺北市公開公車服務：下載路線、站牌、公車位置及到站預估等公開資料。請求不含你的收藏、搜尋文字或定位座標；網路服務仍會收到一般連線資訊。
  • GitHub：提供搜尋別名、介面文字及既有功能設定等內容更新，也代管本支援網站。更新請求不含定位或搜尋文字。GitHub 可能依其政策處理 IP 與其他連線紀錄。詳見 GitHub 隱私聲明。

服務商保留的 IP 等連線資訊可能構成可辨識來源的個人資料；商店申報將這類資料列為服務功能用途，匿名服務紀錄則列為診斷資料。這些服務可能在境外處理網路請求。服務商的紀錄保留與資料權利依各自政策辦理。本 App 不將這些資料用於廣告或跨服務使用者追蹤。

保存在手機的資料

收藏站牌、最近查看的路線與站牌、最近目的地、地圖偏好、最近定位與下載快取保存在本機。這些個人偏好不會由本 App 上傳給開發者。刪除 App 可移除其本機資料；若恢復裝置備份，本機資料可能隨備份還原。

主動聯絡與測試回饋

你主動來信時，我們會收到寄件信箱與你選擇提供的內容，以回覆及處理問題。請避免附上不必要的敏感資料。支援信件只用於處理問題，完成後不再需要時刪除；你也可來信要求刪除。

TestFlight 測試期間，Apple 與開發者可能收到你提交的回饋、截圖及 Apple 提供的測試診斷資訊，依 Apple 的服務規則處理。正式版未加入第三方當機回報或行為分析工具。

你的選擇與聯絡方式

可以隨時在 iPhone「設定」撤回定位權限，或改用手動出發地。若對資料處理有疑問，或希望查詢、更正、刪除主動提供的支援資料，請聯絡 Rio：rio10255254@gmail.com。第三方服務持有的資料，請依其隱私政策向該服務申請。

政策更新

若資料處理方式改變，將在此頁更新生效日期，並同步調整 App 內說明與商店申報。
