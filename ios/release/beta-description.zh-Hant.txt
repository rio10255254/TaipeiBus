1.1.1 TestFlight 實驗版：同一種灰色公車，從街道跟車到全城車流。

首頁點「全城」，縮遠時公車輪廓與明暗逐漸淡化，形成柔和灰色車流；放大後恢復車頂、車窗與輪胎細節。車輛平順銜接已收到的位置，點車跟隨，關閉選取回到先前城市視野。新內容僅供測試；App Store 1.0.0 維持原送審版本。

在 3D 地圖查看台北市區公車的位置、路線方向與官方到站預估。

首頁輸入「你想去哪裡」，可以搜尋地點、地址或站名。使用目前位置或手動出發地，找附近可搭的上車站、目的地附近的下車站，以及直達或一次轉乘公車方案。步行路線與導航使用 iPhone 原生 Apple 地圖。

選方案時可看到整趟預估時長，包含步行、候車與車程。選定後直接顯示上車站牌、站牌方向與地址、要搭的路線方向及下車站。官方下一班到站預估與各車預估分開顯示；點任一車牌即可在地圖跟車，點「到站車輛」可看已發車的後續車輛。步行到站牌可先在目前地圖查看，或從行程開啟 Apple 地圖。

上車後固定使用你確認的車牌，顯示下一站與下車時間；「沿途站牌」列出這輛車到各站的預估。尚未選車牌時可依車內或車身顯示選擇。藍色定位點與公車站牌圖示區分，加上手機方向光暈。

完整收錄臺北市公開 API 的主路線與行駛版本，支援路線名稱、英文代碼、起訖站及支線搜尋。主路線可查看全部走法，也能切到個別走法，查看對應方向的車輛、站序與軌跡。

不需登入。定位權限為選用，拒絕定位後仍可手動選擇出發地。最近目的地只保存在手機。公車資料使用臺北市公開 API，地圖使用 MapLibre Native 與 OpenFreeMap；地點搜尋與步行起終點由 Apple 地圖處理。

官方到站預估屬於路線／站牌，來源沒有車牌綁定。各車時間依已收到的位置、近期行駛及通過各站的紀錄估算，會隨回報更新；時間說明可查看參考範圍。上車後紀錄不足時採一般路段車程並標示為參考，位置無法確認或資料過期時暫停顯示。整趟時長若缺少班次資料，會標明包含估計候車時間。公車位置不是車道級定位，也不繪製尚未收到的未來 GPS。
