# 一路宣傳片系列：七支功能片＋一支發佈片

直式 1080×1920、60 fps、每分鐘 120 拍。一支只講一件事，前三秒就讓人看到那個功能在動；最後一律落在同一張片尾與同一段聲音 logo。做法參考 WordCat 單字貓的上架倒數系列（腳本 → 配音 → 排拍點與配樂 → 畫面），但畫面、文案、配樂與聲音 logo 都是「一路」自己的。

## 共用規格

| 項目 | 規格 |
| --- | --- |
| 主角 | App 的真實畫面。畫面來自 `AppStoreScreenshotTests` 用即時資料擷取的截圖（`public/shots/`），不改畫面內容；浮起、標籤、手指、光圈都是疊在上面的示意。 |
| 鏡頭 | 一支手機、一顆鏡頭、不硬切：手機在句子之間滑到下一個位置，慢慢推近；換功能時像翻牌一樣轉 90 度，側面朝鏡頭那一格換畫面。手機永遠有很小的搖晃，玻璃上有一道隨角度移動的反光。 |
| 浮起 | 這一句在講的那一塊畫面，從玻璃上浮向鏡頭（真的透視、帶陰影，重點塊有琥珀色外框），落在拍點上。 |
| 標籤 | 琥珀色小標籤彈出，說明浮起的那一塊是什麼；一個鏡頭最多一張。 |
| 封面 | 第一格就是封面：左上角圖示與「一路 OneRoad ＃幾」，兩行大標（一個提問，重點詞用琥珀色加一筆螢光），手機從下方升起。 |
| 字幕 | 深色圓角字幕帶，固定在畫面下方三分之一（避開平台的按鈕列）；字跟著配音一個個亮起，重點詞琥珀色。封面那句只有大標，不重複字幕。 |
| 片尾 | 從畫面中央圓形展開到深藍底：圖示彈出、「一路」由左而右顯露、一條琥珀色的線依序接起「公車—捷運—YouBike—步行」四個站點、下載鈕彈出。 |
| 配色 | 每支一個底色：夜藍（3D 地圖、發佈）、石板藍（品牌色）、霧白、沙色、青苔綠（YouBike）。重點色一律琥珀。 |
| 旁白 | ElevenLabs「Yu 小宇」（台灣口音），模型 `eleven_v4`。語氣像一個很會搭車的朋友：先問一個每個人都遇過的問題，再用三句話回答。 |
| 配樂 | D 大調、Bm7 → Gmaj7 → D → A 循環。悶音吉他、往上爬的馬林巴（像路線一站一站畫出來）、走動的貝斯、鐵琴點在強拍。第二句起大鼓加滿。旁白說話時配樂自動退後。 |
| 聲音 logo | A–D–F♯ 三個往上的音，落在 D 和弦，像月台的到站提示音。 |
| 音效 | 鏡頭移動「咻」、浮起「啵」、點擊「嗒」、翻牌「唰」、重點出現時兩聲鐵琴。全部壓得很輕。 |
| 長度 | 每句 4 秒左右（8～9 拍），四句加 4 秒片尾，約 21 秒。 |

## 內容正確性

- 畫面裡的車牌、到站時間、路線都是擷取當下的即時資料，沒有重畫或修改。
- 文案只說 App 真的會做的事：「縮放也不會跟丟」「借車站有車、還車站有空位才會提出」「沒有廣告、不用登入」都對得上 App 的行為與隱私說明。
- 到站時間是官方預估，片中不說「準時」或「保證」。

## 各集

每集的時間點、浮起的區塊（截圖像素座標）、標籤位置都寫在 `src/episodes.json` 該集的 `shots` 裡。

### ＃1 公車到哪了（夜藍）

**要讓人記住**：不用猜，地圖上直接看那輛車開過來。

| 段 | 台詞 | 畫面與動態 |
| --- | --- | --- |
| 0 封面 | 站牌寫三分鐘，**車到底在哪**？ | 手機從下方升起，螢幕是 3D 地圖上正在走的 939。第二拍起，公車位置冒出一圈圈琥珀色光圈。 |
| 1 | 打開地圖，**看它開過來**。 | 鏡頭推近到那輛車。光圈收掉，車牌標籤「939 KKA-3372」連同公車浮起；標籤「車牌、路線／每輛車都看得到」。 |
| 2 | 點一下那輛車，**鏡頭跟著它走**。 | 手指點車牌標籤，車輛卡片淡入；鏡頭往下滑到卡片，「跟隨公車」鈕浮起並被點下。標籤「跟隨公車／縮放也不會跟丟」。 |
| 3 | 下一班還要多久，**一眼看完**。 | 「官方下一班・1 分鐘內」整列浮起，接著時速與回報時間那一列；手機翻牌換成站牌畫面，站牌標籤與「967直 1 分鐘內」浮起。標籤「點站牌也看得到」。 |
| 片尾 | 一路，App Store 免費下載。 | 共用片尾。 |

### ＃2 怎麼去最快（霧白）

**要讓人記住**：公車、捷運、YouBike 放在一起比，連走路和等車都算進去。

| 段 | 台詞 | 畫面與動態 |
| --- | --- | --- |
| 0 封面 | 搭公車、捷運，**還是騎車**？ | 手機升起，螢幕是路線比較：上半地圖畫著整趟路線，下半是方案卡。 |
| 1 | 輸入目的地，**幾種走法一起比**。 | 鏡頭推近方案區。第一名的卡片浮起，接著下面兩張替代方案一拍一張浮起。 |
| 2 | 走路、等車都算進去，**幾點到直接寫給你**。 | 第一名卡片裡「約 41 分鐘／含候車／抵達時刻」那一塊浮起；步行、捷運的圖示列跟著浮起。標籤「整趟時間」。 |
| 3 | 看完步驟，**按出發才開始帶路**。 | 手指點「出發」旁的步驟，畫面推入完整行程；綠色「出發」鈕浮起。 |

### ＃3 每一步先看清楚（沙色）

**要讓人記住**：轉車不怕坐過站，上車、坐幾站、哪裡下車都寫好了。

| 段 | 台詞 | 畫面與動態 |
| --- | --- | --- |
| 0 封面 | 轉車最怕**坐過站**？ | 手機升起，螢幕是完整行程。 |
| 1 | 出發前，**整趟先看一遍**。 | 鏡頭由上往下沿著行程慢慢滑；「步行至 國父紀念館」那一段浮起。 |
| 2 | 哪裡上車、坐幾站、**哪裡下車**。 | 「搭乘 板南線・搭乘 6 站・在南港展覽館下車」那一塊浮起，接著文湖線那一塊。標籤「坐幾站都寫好」。 |
| 3 | 走到站牌，**App 裡直接帶你走**。 | 翻牌換成 App 內步行畫面：上方深色指示橫幅浮起，再來是「約 4 分・259 m」卡片。 |

### ＃4 這班車趕不趕得上（石板藍）

**要讓人記住**：車還有幾分鐘、走過去要幾分鐘，一起看就知道要不要跑。

| 段 | 台詞 | 畫面與動態 |
| --- | --- | --- |
| 0 封面 | 這班車，**要不要用跑的**？ | 手機升起，螢幕是站牌畫面，站牌上方標籤寫著「1 分鐘內」。 |
| 1 | 車還有幾分鐘，**點站牌就知道**。 | 鏡頭推近站牌；手指點站牌，標籤與到站時間浮起，光圈一圈圈。 |
| 2 | 走過去要多久，**地圖上直接帶路**。 | 翻牌換成步行畫面；藍色虛線路徑所在的地圖區塊浮起，接著「約 4 分・259 m」。 |
| 3 | 趕不趕得上，**出門前就知道**。 | 鏡頭拉遠到整支手機；「已到站牌」鈕浮起並被點下。 |

### ＃5 最後一段路（青苔綠）

**要讓人記住**：捷運站出來還有一段路，YouBike 直接排進路線裡，而且先看好有沒有車。

| 段 | 台詞 | 畫面與動態 |
| --- | --- | --- |
| 0 封面 | 出了捷運站，**還要走十五分鐘**？ | 手機升起，螢幕是含 YouBike 的路線比較。 |
| 1 | 規劃路線時，**YouBike 一起排進去**。 | 鏡頭推近方案區；兩張「YouBike 接駁」方案卡一拍一張浮起。 |
| 2 | 騎車快多少、車資多少，**寫在旁邊讓你選**。 | 兩張卡的「約 39 分鐘／車資」浮起；第一名卡片的「不用借還車」也浮起做對比。 |
| 3 | 借車站有車、還車站有位，**它才會這樣排**。 | （有 YouBike 車位畫面時）翻牌換成站點卡，「可借／可還」浮起；沒有時停在方案卡並加標籤「有車有位才提出」。 |

### ＃6 找路線、找站牌（沙色）

**要讓人記住**：找路線不用打字，按幾下就到；整條線都在地圖上。

| 段 | 台詞 | 畫面與動態 |
| --- | --- | --- |
| 0 封面 | 找一班公車，**還在慢慢打字**？ | 手機升起，螢幕是路線鍵盤。 |
| 1 | 紅、藍、棕、綠，**按一下就帶入**。 | 鏡頭推近鍵盤；手指依序點「藍」「2」「7」，每點一下那顆鍵浮起。 |
| 2 | 路線馬上出來，**起訖站寫清楚**。 | 鏡頭上移到搜尋框與結果列；「藍 27 內湖行政中心 → 捷運市政府站」浮起。 |
| 3 | 附近的站牌，**打開就在首頁**。 | 翻牌換成首頁；兩個附近站牌入口浮起，再來是搜尋列。 |

### ＃7 打開就能用（石板藍）

**要讓人記住**：沒有廣告、不用登入，規劃、導航、到站時間都免費。

| 段 | 台詞 | 畫面與動態 |
| --- | --- | --- |
| 0 封面 | 查個公車，**還要先看廣告**？ | 手機升起，螢幕是首頁地圖。 |
| 1 | 一路沒有廣告，**也不用登入**。 | 鏡頭推近首頁；標籤「沒有廣告」「不用登入」一拍一張貼上；搜尋列浮起。 |
| 2 | 規劃、導航、到站時間，**全部免費**。 | 每說一個詞翻一次牌：路線比較 → 步行導航 → 車輛到站。每一站那個功能最有代表性的一塊浮起。 |
| 3 | 台北、新北，**打開就看得到**。 | 翻回首頁，手機退後到全身；標籤「台北＋新北」。 |

| 段 | 台詞 | 畫面與動態 |
| --- | --- | --- |
| 0 封面 | 一路，**全新上線**。 | 封面大標「一路 1.9／**全新上線**」。手機升起，螢幕是 3D 公車。 |

## 製作

```bash
cd promo && npm install
python3 scripts/make-voice.py ep1        # 改台詞才需要（需要 ElevenLabs）
python3 scripts/make-sound.py ep1        # 排時間、配樂、音效、母帶；寫出 src/timing.json
node scripts/render.mjs ep1 --preview    # 半尺寸 30 fps，先看設計
node scripts/render.mjs ep1              # 成品 out/oneroad-ep1.mp4
```
