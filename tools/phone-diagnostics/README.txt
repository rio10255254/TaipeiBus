台北公車：動態島顯示檢查

請在「實際插著 iPhone 傳輸線」的 Windows 電腦使用。

1. 將整個 ZIP 解壓縮，開啟 Start.cmd。
2. 保持手機解鎖；若出現「信任這部電腦」，請在手機上按信任。
3. 畫面顯示已連接後，按 Enter。接著在手機重新開始導航，退回主畫面、
   長按動態島，讓空白畫面停留 20 秒。兩分鐘後工具會自動結束。

完成後，把 reports 資料夾中產生的 ZIP 報告提供給我。
若未能連線，報告仍會記下未完成的原因。

工具只讀取顯示相關紀錄，不會安裝手機 App、備份或更改手機資料，
不會自行上傳報告。它會遮去常見的識別碼、引號中的內容及導航資料。
完整手機紀錄不會儲存；只保留台北公車相關內容與特定顯示錯誤。

這台 Windows 需要 Apple Devices 或 iTunes 的正常手機連線支援。
若未安裝，請依 Apple 官方說明操作：https://support.apple.com/zh-tw/108643
無須啟用 iPhone 開發者模式，也無須付費。

內附官方 Python 可攜執行環境與 pymobiledevice3，無須另行安裝 Python。
來源與授權保留於 runtime 資料夾及各套件的 dist-info 資料夾。
